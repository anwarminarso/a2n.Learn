# Aturan data

- Default semua modul: dataset bawaan scikit-learn atau data sintetis dari generator di repo, tanpa unduhan. Data publik hanya pengecualian: sumber dan lisensi jelas, salinan kecil di repo, dan harus disetujui Frieren atau mas Anwar dulu. Modul 8 memakai data sintetis ala tambang. Tanpa data ANTAM.
- Data publik yang sudah disetujui: dokumentasikan sumber dan lisensinya di README modul; jangan mengarang nama dataset atau lisensi.
- **Dilarang** menyimpan secret (password, token, connection string).
- File data mentah tidak di-commit (lihat `.gitignore`), kecuali salinan kecil data publik yang sudah disetujui.
