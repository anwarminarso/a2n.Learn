# Aturan data

- Hanya dataset **bawaan scikit-learn** atau data **sintetis yang dibangkitkan kode** (boleh meniru kasus tambang). Tidak perlu unduhan.
- Dokumentasikan sumber (dan lisensi bila ada) setiap dataset di README modul yang memakainya. Jangan mengarang nama dataset atau lisensi.
- **Dilarang** memakai data ANTAM atau data internal kerja apa pun.
- **Dilarang** menyimpan secret (password, token, connection string).
- File data mentah tidak di-commit (lihat `.gitignore`); hanya README ini.
